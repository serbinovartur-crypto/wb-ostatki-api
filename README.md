# wb-ostatki-api

Бэкенд-фундамент для сайта "Остатки товара" (wb-ostatki на GitHub Pages).

Сейчас хранит общий (для всех устройств) порядок строк по каждой вкладке.
В будущем на этот же сервис можно добавить:
- синхронизацию остатков через Wildberries Seller API
- ИИ-помощника с рекомендациями по товару

## Переменные окружения (задаются в Railway)

- `DATABASE_URL` — подставляется автоматически, если в проекте подключён Postgres.
- `API_KEY` — произвольная строка-пароль для операций записи (PUT). Если не задать — запись будет доступна без пароля (не рекомендуется для публичного сайта).

## Эндпоинты

- `GET /health` — проверка, что сервис жив.
- `GET /api/state/:key` — прочитать значение по ключу (публично, без пароля).
- `PUT /api/state/:key` — записать значение по ключу. Требует заголовок `X-Api-Key: <API_KEY>`, если переменная `API_KEY` задана.

Ключи, которые использует сайт сейчас: `order:upakovannye`, `order:neupakovannye`, `order:obshee`, `order:svitshoty`, `order:brak`.
